# 📶 Wi-Fi Scanner на Python

Простой и безопасный сканер Wi-Fi сетей на Python, использующий библиотеку [`pywifi`](https://pypi.org/project/pywifi/).  
Сканирует доступные точки доступа без подключения и без взлома. Подходит для образовательных и диагностических целей.

---

## 🔧 Установка

1. Клонируйте репозиторий или загрузите код:

   ```bash
   git clone https://github.com/yourusername/wifi-scanner.git
   cd wifi-scanner
   ```
   
## 🚀 Запуск
Запустите скрипт:
   ```bash
     python scanner.py
   ```
После запуска программа выведет список всех доступных Wi-Fi сетей с параметрами:

SSID — имя сети

BSSID — MAC-адрес точки доступа

Signal — уровень сигнала в dBm

Security — тип защиты (OPEN или SECURED)

## 🛡️ Безопасность
❌ Не подключается к сетям

❌ Не перехватывает трафик

✅ Только безопасное чтение информации, доступной через Wi-Fi адаптер

## 🖥️ Требования
Python 3.6+

Windows (тестировалось) или Linux

Наличие Wi-Fi адаптера

(На Windows) запуск от имени администратора может быть нужен для доступа к адаптеру
